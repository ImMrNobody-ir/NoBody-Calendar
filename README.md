## 🌌 درباره پروژه

**NoBody Calendar** یک اپلیکیشن تقویم اندرویدی است که با هدف ارائه تجربه‌ای متفاوت، مدرن و کاربردی برای مدیریت زمان طراحی شده است.

این برنامه با ترکیب امکانات تقویم و ابزارهای برنامه‌ریزی شخصی، به کاربران کمک می‌کند تا تاریخ‌ها، فعالیت‌های روزانه و برنامه‌های خود را در یک محیط یکپارچه مدیریت کنند.

از طراحی مدرن گرفته تا امکانات کاربردی، هدف NoBody Calendar ایجاد تجربه‌ای ساده و لذت‌بخش برای استفاده روزمره است.
